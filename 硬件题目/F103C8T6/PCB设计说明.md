# STM32F103C8T6 最小系统板 PCB 设计说明

## 1. 项目概述

本 PCB 为基于 STM32F103C8T6 的最小系统开发板，用于 STM32 程序开发、在线调试、串口通信、CAN 通信。

主要功能如下：

- 采用 STM32F103C8T6 作为主控芯片；
- 使用 8 MHz 外部晶振提供系统时钟；
- 采用 AMS1117 实现 5 V 转 3.3 V 稳压，提供 150 mA 电流；
- 具有复位按键；
- SWD 调试接口，支持 ST-LINK 和 DAP-LINK 下载；
- 一个电源指示灯；
- 一个功能指示灯，由PC13控制，用于简单 IO 测试；
- USART1 串口接口，用于串口下载和通信；串口接口引出 5 V、GND、TX、RX；
- Type-C 外部 5 V 供电接口；
- 独立 CAN 端子，便于 CAN 通信；
- 引出 PA0 至 PA8、PA15、PB0 至 PB9 GPIO。

PCB 采用四层结构：顶层、GND 层、POWER 层和底层。设计目标是在满足最小系统功能的基础上，保证 SWD 与 CAN 等关键信号的布线质量，并提供稳定的电源和地参考平面。

## 2. 设计依据与资料

本设计依据以下资料完成：

- STM32F103C8T6 最小系统原理图；
- STM32F103C8T6 芯片数据手册；
- 8 MHz 晶振、AMS1117、Type-C 接口及相关连接器的数据手册；
- PCB 元器件封装库；
- PCB 设计文件及输出的原理图、PCB 图纸。

PCB 设计遵循常规 PCB 设计规范，并参考 IPC-2221 通用 PCB 设计要求进行布局布线、间距和可制造性检查。

## 3. 电气设计说明

### 3.1 原理图逻辑

系统以 STM32F103C8T6 为核心。Type-C 接口输入 5 V 电源，电源指示灯用于指示 5 V 电源状态，经 AMS1117 稳压后生成 3.3 V，为主控及板载电路供电。

8 MHz 晶振连接至 STM32 的外部时钟引脚，为系统提供时钟源。复位按键连接 NRST 引脚，用于手动复位。

SWD 接口引出 SWDIO、SWCLK、3.3 V 和 GND 信号，用于 ST-LINK 或 DAP-LINK 下载与调试。

USART1 用于串口下载和通信，接口引出 5 V、GND、TX、RX 信号。功能指示灯连接至 GPIO PC13，用于程序运行及 IO 测试。

CAN 通信信号通过 CANH、CANL 引出至独立 CAN 端子。

### 3.2 电源设计

外部 5 V 电源由 Type-C 接口输入，通电时电源指示灯亮，5V 电源经 AMS1117 转换为 3.3 V。

电源输入端、AMS1117 输入端和输出端设置滤波电容，输出端额外设置磁珠接入VDDA为芯片内部时钟供电，以减小电源噪声并提高系统稳定性。

四层板中，第二层为完整 GND 平面，第三层为 POWER 层，用于 5 V 和 3.3 V 电源分配。GND 层为高速及数字信号提供连续回流路径。

### 3.3 关键信号处理

SWDIO、SWCLK、CANH、CANL 为本板关键布线信号，优先安排在顶层通过。

SWDIO、SWCLK 走线尽量短且连续，减少过孔和分支，并保证下方具有连续 GND 参考平面。

CANH、CANL 采用差分对方式布线，保持线宽、线距一致，走线长度尽量匹配，避免直角拐角和不必要分支。CAN 差分对按120欧阻抗匹配要求进行布线。

顶层除关键信号外，也布设不影响高速信号质量的低速信号线。底层布设少量低速信号线用于避开元器件区域。

### 3.4 EMI/EMC 措施

- GND 内层保持连续，减少高速信号回流路径中断；
- 晶振靠近 STM32 放置，晶振走线尽量短；
- SWD 与 CAN 关键信号避免靠近电源转换区域；
- 电源输入及稳压器附近布置滤波和去耦电容；
- CANH、CANL 保持成对布线，减小共模干扰；
- 顶层和底层地铜通过地过孔与 GND 内层连接。

## 4. 结构与布局

### 4.1 板框尺寸与形状

PCB 板框为尺寸 55*35 mm 的矩形，圆角半径 2 mm

### 4.2 层叠结构

本 PCB 采用四层铜箔结构，各层用途如下：

| 层名称 | 用途 |
| --- | --- |
| 顶层 Top Layer | 元器件放置、SWDIO、SWCLK、CANH、CANL 等关键信号，以及部分低速信号 |
| 第二层 GND | 完整地平面，为信号提供回流路径 |
| 第三层 POWER | 5 V、3.3 V 电源分配 |
| 底层 Bottom Layer | 为避开元器件而布设的少量低速信号及串口和SW调试引脚 |

### 4.3 元器件布局原则

STM32、8 MHz 晶振及去耦电容构成最小系统核心区域。晶振和去耦电容应靠近 STM32 对应引脚放置。

Type-C 接口、AMS1117 及其输入输出滤波电容布置在电源输入区域，缩短 5 V 输入和 3.3 V 输出回路。

SWD、USART1、CAN 及 GPIO 接口布置在板边，便于连接下载器、串口模块、CAN 线缆和外部模块。

CAN 端子附近布置 CANH、CANL 相关电路，缩短 CAN 差分信号至接口端子的路径。

## 5. 布线规则与工艺要求

### 5.1 布线规则

- SWDIO、SWCLK、CANH、CANL 优先在顶层布线；
- CANH、CANL 按差分对规则布线，保持线宽和线距一致；
- 关键信号避免跨越 GND 平面分割区域；
- 顶层可布设部分低速信号，但不得影响高速及差分信号走线；
- 底层仅布设少量低速信号，用于绕开元器件；
- 电源网络通过 POWER 层进行分配；
- 关键信号尽量减少过孔数量；
- GPIO 及其他低速信号按常规数字信号规则布线。

### 5.2 Class 分组

| 信号类别 | 包含信号 | 布线要求 |
| --- | --- | --- |
| SWD 信号 | SWDIO、SWCLK、NRST | 顶层优先、走线短、减少过孔、保持连续 GND 参考 |
| CAN 差分信号 | CANH、CANL | 差分对布线、阻抗匹配、长度尽量匹配 |
| 电源信号 | 5 V、3.3 V、GND | 使用 POWER 层和 GND 层进行分配 |
| 串口信号 | USART1 TX、RX | 常规数字信号布线 |
| GPIO 信号 | PA0 至 PA8、PA15、PB0 至 PB9 | 常规低速数字信号布线 |
| 指示灯信号 | 电源 LED、功能 LED | 常规低速信号布线 |

## 6. 测试与验证

### 6.1 连通性测试

检查 5 V、3.3 V 和 GND 网络是否存在短路；检查 SWD、USART1、CAN 及 GPIO 接口与 STM32 对应引脚的连通性，并通过DRC检查。

### 6.2 功能测试

- 检查 Type-C 接口是否可正常输入 5 V；
- 检查 AMS1117 输出是否为稳定的 3.3 V；
- 检查电源指示灯是否正常点亮；
- 检查复位按键功能；
- 使用 ST-LINK 或 DAP-LINK 检查 SWD 下载与调试功能；
- 使用 USART1 检查串口下载和串口通信功能；
- 使用功能指示灯进行 GPIO 输出测试；
- 检查 CAN 端子通信功能；
- 检查 PA0 至 PA8、PA15、PB0 至 PB9 GPIO 引出功能。

### 6.3 EMC 测试

重点检查电源输入、AMS1117 稳压电路、SWD 信号及 CAN 差分信号的抗干扰表现，并确认 CAN 通信过程稳定。
