# 24V转5V降压电源设计方案

## 1. 设计目标

机器人整机采用24V直流电源供电，但系统中的小型主机、控制模块或部分外设需要5V直流电源。因此需要设计一套24V转5V的降压电源方案，为5V设备提供稳定供电。

本设计的目标如下：

| 项目 | 设计要求 |
|---|---|
| 输入电压 | 24V直流 |
| 输出电压 | 5V直流 |
| 输出电流 | 不小于1A |
| 推荐输出能力 | 5V/3A |
| 使用场景 | 机器人系统内部5V设备供电 |

本设计不采用线性稳压方案。若使用线性稳压器将24V降至5V，在1A负载下，线性稳压器自身功耗为：

```text
P = (24V - 5V) × 1A = 19W
```

19W损耗会造成严重发热，效率低，不适合机器人系统中的持续供电。

本设计选择Buck（降压型）电路拓扑，并采用市面上成熟的降压芯片。Buck拓扑适用于输入电压高于输出电压的场景，可直接将24V直流电压转换为5V直流电压，不需要额外的升压或反相级。与线性稳压方式相比，Buck拓扑通过开关器件、电感和电容进行能量转换，能够降低转换过程中的功率损耗和发热量，适合机器人系统中5V设备的持续供电。

## 3. 最终选择及理由

本设计最终选择 **AP63205WU-7** 作为24V转5V降压电源的核心器件。

### 3.1 选择理由

与LM2596S-5.0和XL4015E1相比，AP63205WU-7具有以下优势：

1. **开关频率最高**

   AP63205WU-7的开关频率为1.1MHz，高于LM2596S-5.0的150kHz、XL4015E1的180kHz和MP4583GQVE-Z的400kHz。在相同输出条件下，较高的开关频率可以使用体积更小的电感和滤波器件，有利于缩小电源电路体积。

2. **采用同步整流**

   LM2596S-5.0和XL4015E1采用异步整流，需要使用外部续流二极管。AP63205WU-7采用同步整流，通过内部MOSFET代替续流二极管，减少了二极管正向压降造成的功率损耗。

   在`VIN=24V、VOUT=5V、IOUT=1A`的对比条件下，AP63205WU-7典型效率约为90%，高于LM2596S-5.0的约82%和XL4015E1的约88%。因此，AP63205WU-7在相同负载下具有更低的功耗和发热量。

3. **价格最低**

   根据表中的立创商城价格，AP63205WU-7单价为￥2.75/片，低于LM2596S-5.0的￥3.72/片、XL4015E1的￥4.09/片和MP4583GQVE-Z的￥16.8/片。

4. **输出电流满足设计要求**

   AP63205WU-7的最大输出电流为2A，本设计要求输出电流不小于1A，因此AP63205WU-7具有1A的输出电流余量，可以满足小型主机及其他5V设备的供电要求。

5. **性能和成本匹配**

   与MP4583GQVE-Z相比，MP4583GQVE-Z具有更大的输入电压范围、更大的输出电流和更高的效率，但其价格明显更高。本设计的输入电压为24V，输出电流要求不低于1A，AP63205WU-7的3.8V～32V输入范围和2A输出能力已经满足使用要求，MP4583GQVE-Z更高的电压、电流和效率指标没有必要。

### 3.2 选型结论

综合开关频率、整流方式、效率、输出能力和价格，AP63205WU-7在本设计中具有最好的综合性价比。

因此，本设计采用：

```text
输入电压：24V
输出电压：5V
最大输出电流：2A
核心器件：AP63205WU-7
```

## 4. PCB设计

本电路参考AP63205WU-7官方典型应用电路进行设计。AP63205WU-7为固定5V输出版本，因此反馈端FB直接连接到5V输出端，不需要外部分压电阻设置输出电压。官方典型电路中主要包括输入电容、Buck电感、输出电容和自举电容，本设计在此基础上增加了5V电源指示灯，用于判断5V输出是否正常。

### 4.1 原理图设计

电路连接关系如下：

```text
24V输入
  |
  +-- 输入电容CIN
  |
  +-- AP63205WU-7 VIN引脚

AP63205WU-7 SW引脚
  |
  +-- 电感L
  |
  +-- 5V输出

5V输出
  |
  +-- 输出电容COUT
  |
  +-- FB引脚
  |
  +-- 限流电阻RLED
  |
  +-- LED电源指示灯
  |
  +-- GND
```

主要外围器件如下：

| 器件 | 作用 | 参考取值 |
|---|---|---:|
| CIN | 输入滤波电容 | 10uF |
| COUT | 输出滤波电容 | 2 × 22uF |
| L | 储能电感 | 4.7uH |
| CBST | 自举电容 | 100nF |
| LED | 5V电源指示灯 | 普通贴片LED |
| RLED | LED限流电阻 | 1kΩ |

LED限流电阻按红色LED估算：

```text
R = (5V - 2V) / 3mA = 1kΩ
```

因此，5V指示灯可以采用：

```text
5V输出 -> 1kΩ限流电阻 -> LED -> GND
```

该指示灯只用于显示5V输出状态，不参与电源反馈控制。

### 4.2 PCB布局要求

AP63205WU-7为高频同步Buck芯片，开关频率为1.1MHz，PCB布局会直接影响输出纹波、EMI和芯片温升。因此PCB设计需要重点控制高频电流回路和开关节点面积。

布局要求如下：

1. 输入电容CIN应靠近AP63205WU-7的VIN引脚和GND引脚放置，减小输入高频电流回路面积。
2. 自举电容CBST应靠近BST引脚和SW引脚放置，走线尽量短。
3. 电感L应靠近SW引脚放置，但SW节点铜皮面积不宜过大，避免增加辐射噪声。
4. 输出电容COUT应靠近电感输出端和芯片GND放置，形成短而直接的输出滤波回路。
5. FB走线从5V输出电容正端引出，并远离SW节点、电感和其他高dv/dt走线。
6. GND应采用完整地平面，输入电容地、输出电容地和芯片GND应低阻连接。
7. 5V输出走线按实际负载电流加宽，避免因走线压降导致小型主机端电压偏低。
8. LED指示灯支路应接在5V输出端之后，不能串入主供电路径。

### 4.3 PCB设计结论

本PCB以AP63205WU-7官方典型应用电路为基础，保留输入滤波、电感储能、输出滤波和自举电容等Buck电路必要部分。同时增加5V电源指示灯，方便调试和使用时观察5V输出状态。

在PCB布局中，应优先保证输入电容、芯片、电感和输出电容组成的主功率回路紧凑，减小SW节点面积，并将FB反馈走线远离开关节点，从而降低纹波和电磁干扰。
