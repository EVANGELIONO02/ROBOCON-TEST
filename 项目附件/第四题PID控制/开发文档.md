# 4_PID_FAN 开发文档

## 1. 项目目标

使用 STM32F103xB 实现 MG310 减速电机的闭环控制。支持速度和定位两种模式。用户通过旋钮设定目标，按钮切换模式，编码器反馈实时数据至 VOFA+。

- **速度模式**：旋钮控制目标转速（0-400 RPM），电机匀速转动
- **定位模式**：旋钮控制目标角度（±2 圈），电机转到位置后停止

## 2. 硬件连接

### 2.1 开发板

- **主控**：STM32F103xB (72 MHz)
- **驱动**：TB6612FNG 双 H 桥
- **电机**：MG310 (1:20 减速比，500 线编码器，额定 400 RPM)
- **通信**：USART1 (VOFA+ 遥测)

### 2.2 引脚配置

| 功能 | 引脚 | 配置 |
|------|------|------|
| PWM 输出 | PA0 | TIM2_CH1 (1 kHz) |
| 电机方向 A | PA1 | GPIO 推挽 |
| 电机方向 B | PA2 | GPIO 推挽 |
| 旋钮 ADC | PA3 | ADC1_IN3 |
| 模式按钮 | PA4 | GPIO 输入 + 上拉 |
| 编码器 A | PA6 | TIM3_CH1 (正交) |
| 编码器 B | PA7 | TIM3_CH2 (正交) |
| USART TX | PA9 | 115200 baud |
| USART RX | PA10 | 115200 baud |

### 2.3 外部连接

```text
TB6612FNG:
  PWMA   <- PA0 PWM
  AIN1   <- PA1 方向
  AIN2   <- PA2 方向
  STBY   -> 5V (高电平有效，驱动芯片使能)
  VM     -> 电源 (12V 或电机额定电压)
  GND    <- 共地
  AO1/AO2 -> 电机 A/B 端子

编码器:
  A/B    -> PA6/PA7
  GND    <- 共地
  VCC    -> 3.3V

USART:
  PA9 (TX) -> TTL 模块 RX
  PA10 (RX) <- TTL 模块 TX
```

## 3. CubeMX 配置

### 3.1 GPIO

PA1, PA2 配置为推挽输出（方向控制）：

```c
GPIO_InitStruct.Pin = AIN1_Pin | AIN2_Pin;
GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
GPIO_InitStruct.Pull = GPIO_NOPULL;
```

PA4 配置为输入 + 上拉（模式按钮）：

```c
GPIO_InitStruct.Pin = Mode_switch_Pin;
GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
GPIO_InitStruct.Pull = GPIO_PULLUP;
```

### 3.2 ADC1

PA3 输入，10 bit 分辨率：

```text
输入通道：ADC1_IN3 (PA3)
采样时间：1.5 cycles
分辨率：12 bit (取高 10 bit 有效)
模式：软件启动，单次转换
```

### 3.3 TIM2 (PWM)

PA0 输出 1 kHz PWM，占空比 0-100%：

```text
Prescaler = 72-1       (1 MHz)
Period = 1000-1        (1 kHz)
Channel 1 = PWM1       (PA0)
初始 Pulse = 0
```

占空比公式：`CCR1 = duty × (Period+1) / 100`

### 3.4 TIM3 (编码器)

PA6/PA7 正交编码器模式，4 倍频：

```text
Mode = TI1 & TI2 (4x Encoding)
CH1 = Rising Edge
CH2 = Rising Edge
Period = 65535         (16 bit 计数器)
Prescaler = 0
```

### 3.5 USART1

PA9/PA10，115200 baud：

```text
波特率：115200
数据位：8
校验位：None
停止位：1
```

## 4. 软件结构

### 4.1 核心模块

```
Core/Inc/
  freertos.c 中定义：
  - PID 控制器结构体
  - 控制模式枚举 (停止/速度/定位)
  - 3 个 PID 任务 + 2 个辅助任务
```

### 4.2 关键常量

```c
ENCODER_COUNTS_PER_REV = 40000  // 500 线 × 4 倍频 × 20 减速比
TARGET_SPEED_MAX_CPS = 270000   // 满量程 ≈ 405 RPM
POSITION_TOLERANCE_DEG = 5      // 定位死区 ±5°
```

编码器分辨率说明：编码器在电机轴（高速端），通过 1:20 减速到输出轴。从控制系统看，一圈输出轴 = 40000 计数。

### 4.3 FreeRTOS 任务

| 任务 | 周期 | 优先级 | 功能 |
|------|------|--------|------|
| InputTask | 10 ms | Normal | ADC 采样，更新目标值 |
| ModeSwitchTask | 20 ms | Low | 按钮去抖，模式切换 |
| SpeedPidTask | 10 ms | Normal | 速度环控制，编码器采样 |
| PositionPidTask | 10 ms | Normal | 位置环控制 |
| VofaTelemetryTask | 50 ms | Low | 格式化+发送遥测 |

## 5. PID 控制

### 5.1 速度环

```c
Kp = 0.6 × 100 / 270000 = 2.22e-4
Ki = 4.0 × Kp = 8.88e-4
Kd = 0
integral_limit = 100 / Ki = 112500
```

满量程误差下输出 60% 占空比。

### 5.2 位置环

```c
Kp = 0.003f       
Ki = 0.001f       // 保险值
Kd = 0.000f
integral_limit = 15000.0f
```

关键：位置目标是累积 counts，无最短路径算法。用户正转 → 电机跟随正转，无反向跳转。

## 6. 遥测输出

### 6.1 FireWater 格式

```
d: mode,target_speed,feedback_speed,pwm,target_pos,feedback_pos\r\n
```

示例：`d: 2,0,15230,35,-40000,5123\r\n`

### 6.2 字段说明

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| mode | uint8 | 0/1/2 | 停止/速度/定位 |
| target_speed | int32 | ±270000 | 目标转速 (counts/s) |
| feedback_speed | int32 | 任意 | 反馈转速 |
| pwm | int8 | -100~+100 | 占空比（符号表示方向） |
| target_pos | int32 | -80000~+80000 | 目标位置 (counts) |
| feedback_pos | int32 | 任意 | 实际位置 (counts) |

## 7. 测试现象

### 7.1 速度模式

1. 按按钮进入速度模式 (mode=1)
2. 旋钮最小，电机停止 (target_speed=0)
3. 旋钮最大，电机以 400 RPM 匀速转动

VOFA+ 显示：target_speed 随旋钮平滑变化，feedback_speed 跟踪 target_speed。

### 7.2 定位模式

1. 按按钮进入定位模式 (mode=2)
2. 旋钮中间，电机停止在中点
3. 旋钪逆时针 (0%)，电机转 -2 圈到底
4. 旋钪顺时针 (100%)，电机转 +2 圈到顶
5. 旋钪任意位置，电机光滑转到目标并停止

VOFA+ 显示：feedback_pos 平滑逼近 target_pos，无反向跳转，到位后稳住。

## 8. 调试记录

### 8.1 编码器反向溢出

**症状**：转一圈，feedback_pos 跳到 10 亿+

**原因**：反向时 delta 被当作巨大正数累加

**修复**：用 int16 处理 uint16 减法，自动得到符号

```c
static int32_t Encoder_UpdatePositionCounts(void)
{
  uint16_t current = (uint16_t)__HAL_TIM_GET_COUNTER(&htim3);
  int16_t delta = (int16_t)(current - g_encoder_speed_last_count);
  
  g_encoder_speed_last_count = current;
  g_encoder_position_counts += (int32_t)delta;
  return (int32_t)delta;
}
```

### 8.2 位置模式反向跳转

**症状**：从 10° 转到 350° 时，电机反向冲刺

**原因**：最短路径算法选择 20° 反向

**修复**：改用累积目标，完全遵循旋钮方向

### 8.3 极限环振荡

**症状**：到位后持续高频抖动 (±10%)

**原因**：POSITION_MIN_PWM = 1% 太小，过冲无停止

**修复**：移除最小 PWM，加大死区到 ±5°

### 8.4 调参指南

**速度环**：Kp 从 0.1 逐增至振荡，记 Kp_crit，取 0.6 × Kp_crit

**位置环**：同样方法找到 Kp，加 Ki (Kp/10) 消除稳态误差，Kd 保持 0

## 9. 注意事项

- TB6612 STBY 引脚必须拉高到 5V 或 3.3V（取决于模块）
- 编码器 A/B 接线若反向，feedback_speed 会反号，可交换接线或改代码极性
- 位置模式下旋钮映射：0% → -80000, 50% → 0, 100% → +80000
- 速度环 Ki/Kd 已按 dt=10ms 标度，若改周期需重算
- 现场调参后，更新 POSITION_PID_KP 和 SPEED_PID_KP 宏定义
