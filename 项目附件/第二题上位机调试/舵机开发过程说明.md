# 舵机调试开发过程

## 1. 工程配置

- 芯片：STM32F103C8T6
- 工程：SG90
- 使用 STM32CubeMX 生成 HAL 工程
- 配置 USART1 用于与 VOFA+ 通信
- USART1 参数：115200、8 数据位、无校验、1 停止位
- 串口引脚：PA9 为 TX，PA10 为 RX

## 2. PWM 舵机控制

- 使用 TIM3_CH1 输出 PWM
- PWM 输出引脚：PA6
- 定时器计数频率：100 kHz
- PWM 周期：20 ms
- SG90 控制范围：
  - 0 度：2.5%，CCR = 50
  - 90 度：7.5%，CCR = 150
  - 180 度：12.5%，CCR = 250
- 角度转换公式：

```c
CCR = 50 + angle * 200 / 180;
```

- 使用 `HAL_TIM_PWM_Start()` 启动 PWM
- 使用 `__HAL_TIM_SET_COMPARE()` 修改 CCR，从而改变舵机角度

## 3. VOFA+ 数据回传

STM32 向 VOFA+ 周期发送两个 `float` 数据：

```text
通道 0：当前设定角度
通道 1：PWM 占空比
```

发送格式使用 VOFA+ 的 JustFloat：

```text
float angle
float duty
00 00 80 7F
```

其中 `00 00 80 7F` 是 JustFloat 帧尾。

## 4. VOFA+ 控制舵机

VOFA+ 发送端使用 ASCII/String 模式，输入角度数字并追加回车换行。

示例：

```text
90\r\n
```

STM32 通过 USART1 接收中断逐字节接收数据：

1. 收到 `\r` 或 `\n` 后认为一条命令结束
2. 将角度限制在 `0~180`
3. 根据角度计算 CCR
4. 使用 `__HAL_TIM_SET_COMPARE()` 更新 PWM

## 5. 验证

- 验证重点：
  - PA6 是否输出 20 ms PWM
  - 舵机与 STM32 是否共地
  - 舵机使用独立 5 V 供电
  - VOFA+ 接收协议是否选择 JustFloat
  - VOFA+ 发送协议是否选择 ASCII/String
  - 发送内容是否包含 `\r\n`
  - 舵机是否能被VOFA+控制
