# 第五题 二自由度舵机云台开发文档

## 1. 项目简介

使用两块 STM32F103C8T6 开发板通过蓝牙实现主从控制的二自由度舵机云台系统。

主控端支持两种控制模式：
1. **电位器模式**：通过两个电位器控制云台的水平（Yaw）和俯仰（Pitch）角度
2. **陀螺仪模式**：通过MPU6050姿态传感器控制云台跟随手部运动

从机端接收蓝牙数据并驱动两个SG90舵机实现云台的二自由度运动。

## 2. 硬件连接

### 2.1 主控端

#### 2.1.1 电位器
- 电位器1（Yaw控制）：中间引脚 → PA0（ADC1_CH0）
- 电位器2（Pitch控制）：中间引脚 → PA1（ADC1_CH1）
- 两个电位器的VCC和GND分别连接3.3V和GND

#### 2.1.2 MPU6050陀螺仪
- VCC → STM32 3.3V
- GND → STM32 GND
- SCL → PB6（I2C1_SCL）
- SDA → PB7（I2C1_SDA）
- AD0 → GND（I2C地址=0x68）
- XDA、XCL、INT 悬空

**重要提示：** MPU6050模块需自带上拉电阻（SCL/SDA各4.7kΩ），否则I2C通信会失败。

#### 2.1.3 蓝牙模块HC-05（主机）
- VCC → 5V
- GND → STM32 GND（**必须共地**）
- TXD → PA10（USART1_RX）
- RXD → PA9（USART1_TX）
- STATE → LED（用于指示配对状态）

**HC-05主机AT配置：**
```
AT+ROLE=1        # 设置为主机模式
AT+CMODE=0       # 连接模式：指定地址
AT+BIND=xxxx,xx,xxxxxx  # 绑定从机MAC地址
```

#### 2.1.4 模式切换按键
- 按键 → PB0（内部下拉，上升沿触发中断）
- 按下时连接3.3V

### 2.2 从机端

#### 2.2.1 舵机
- Yaw舵机（水平）：信号线 → PA0（TIM2_CH1）
- Pitch舵机（俯仰）：信号线 → PA1（TIM2_CH2）
- 舵机VCC → 5V电源（**推荐外部独立供电**）
- 舵机GND → STM32 GND

**SG90舵机参数：**
- PWM频率：50Hz（周期20ms）
- 脉宽范围：500us ~ 2500us
- 角度范围：0° ~ 180°

#### 2.2.2 蓝牙模块HC-05（从机）
- VCC → STM32板载5V
- GND → STM32 GND
- TXD → PA10（USART1_RX）
- RXD → PA9（USART1_TX）

**HC-05从机AT配置：**
```
AT+ROLE=0        # 设置为从机模式
```

### 2.3 电源注意事项

1. **主从机共地**：两块开发板的GND必须连接
2. **蓝牙供电**：HC-05必须从STM32板载5V取电，ST-LINK V2输出电流不足（实测仅1.3V）
3. **舵机供电**：建议使用独立5V电源（两个舵机峰值电流可达2A）

## 4. 软件架构

### 4.1 主控端任务

项目使用FreeRTOS多任务架构：

#### Task_ADC_Read（Normal优先级）
- 周期：50ms（20Hz）
- 功能：读取ADC DMA缓冲区，映射0-4095到0-180°
- 输出：`g_adc_yaw_angle`, `g_adc_pitch_angle`

#### Task_MPU6050_Read（Normal优先级）
- 周期：10ms（100Hz）
- 功能：
  1. 初始化MPU6050（失败则使用默认值90°）
  2. 读取6轴原始数据（加速度+陀螺仪）
  3. 互补滤波计算姿态角（PITCH, ROLL）
  4. 角度映射到舵机范围
- 输出：`g_mpu_yaw_angle`, `g_mpu_pitch_angle`

**姿态控制映射（根据实际安装方向调整）：**
```c
// ROLL角（左右倾斜）控制Pitch舵机（俯仰）：-90° ~ +90° → 30° ~ 140°
g_mpu_pitch_angle = (roll + 90) * 110 / 180 + 30;

// PITCH角（前后倾斜）控制Yaw舵机（水平）：-90° ~ +90° → 0° ~ 180°
g_mpu_yaw_angle = (pitch + 90);
```

#### Task_DataSend（High优先级）
- 周期：50ms（20Hz）
- 功能：根据当前模式选择数据源并通过蓝牙发送

```c
if(g_control_mode == MODE_POTENTIOMETER) {
    mode = BT_MODE_POTENTIOMETER;  // 0x01
    yaw = g_adc_yaw_angle;
    pitch = g_adc_pitch_angle;
} else {
    mode = BT_MODE_GYROSCOPE;      // 0x02
    yaw = g_mpu_yaw_angle;
    pitch = g_mpu_pitch_angle;
}
BT_SendPacket(mode, yaw, pitch);
```

#### Task_ModeSwitch（Normal优先级）
- 事件驱动：等待按键中断信号量
- 功能：切换 `MODE_POTENTIOMETER` ↔ `MODE_GYROSCOPE`

### 4.2 从机端任务

#### Task_DataReceive（Realtime优先级）
- 功能：高速轮询UART DMA缓冲区，解析蓝牙数据包
- 关键优化：`osDelay(0)` 让出CPU但不强制延时，避免DMA缓冲区溢出

#### Task_ServoYaw（High优先级）
- 功能：从消息队列读取Yaw角度，控制水平舵机

#### Task_ServoPitch（High优先级）
- 功能：从消息队列读取Pitch角度，控制俯仰舵机

### 4.3 蓝牙通信协议

**数据包格式（6字节）：**
```
[0xAA][mode][yaw][pitch][checksum][0x55]
```

| 字段 | 长度 | 说明 |
|------|------|------|
| 起始标志 | 1字节 | 0xAA |
| 模式 | 1字节 | 0x01=电位器, 0x02=陀螺仪 |
| Yaw角度 | 1字节 | 0-180° |
| Pitch角度 | 1字节 | 0-180° |
| 校验和 | 1字节 | mode ^ yaw ^ pitch |
| 结束标志 | 1字节 | 0x55 |

**示例：**
- `AA 01 5A 5A B5 55`：电位器模式，90°, 90°
- `AA 02 3C 50 6C 55`：陀螺仪模式，60°, 80°

**状态机解析：**
```c
typedef enum {
    STATE_WAIT_HEADER,
    STATE_WAIT_MODE,
    STATE_WAIT_YAW,
    STATE_WAIT_PITCH,
    STATE_WAIT_CHECKSUM,
    STATE_WAIT_TAIL
} BT_RxState_t;
```

## 5. 核心模块实现

### 5.1 ADC驱动（BSP/adc_driver.c）

```c
void ADC_GetAngles(uint8_t *yaw_angle, uint8_t *pitch_angle)
{
    uint32_t adc_yaw = g_adc_buffer[0];
    uint32_t adc_pitch = g_adc_buffer[1];
    
    // 映射 0-4095 到 0-180
    *yaw_angle = (uint8_t)(adc_yaw * 180 / 4095);
    *pitch_angle = (uint8_t)(adc_pitch * 180 / 4095);
}
```

### 5.2 MPU6050驱动（BSP/mpu6050.c）

**初始化配置：**
```c
int8_t MPU6050_Init(void)
{
    // 1. 测试通信（WHO_AM_I = 0x68）
    // 2. 复位设备（等待50ms）
    // 3. 唤醒设备
    // 4. 配置采样率：100Hz
    // 5. 配置低通滤波：94Hz带宽
    // 6. 配置陀螺仪：±250°/s
    // 7. 配置加速度计：±2g
}
```

**互补滤波姿态估计：**
```c
void MPU6050_CalculateAttitude(MPU6050_RawData_t *raw_data, 
                                 MPU6050_Attitude_t *attitude, 
                                 float dt)
{
    // 1. 转换为物理单位（g, °/s）
    float acc_x = raw_data->accel_x / 16384.0f;
    float gyro_x = raw_data->gyro_x / 131.0f;
    
    // 2. 加速度计计算静态角度
    float accel_pitch = atan2(acc_y, sqrt(acc_x*acc_x + acc_z*acc_z)) * 180/PI;
    
    // 3. 陀螺仪积分计算动态角度
    float gyro_pitch = g_attitude.pitch + gyro_x * dt;
    
    // 4. 互补滤波融合（α=0.98）
    g_attitude.pitch = 0.98f * gyro_pitch + 0.02f * accel_pitch;
}
```

### 5.3 舵机驱动（BSP/servo.c）

```c
void Servo_SetAngle(Servo_Channel_t channel, uint8_t angle)
{
    if(angle > 180) angle = 180;
    
    // CCR = 500 + (angle / 180) * 2000
    uint16_t ccr_value = (uint16_t)(500 + (angle * 2000) / 180);
    
    if(channel == SERVO_YAW) {
        __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, ccr_value);
    } else {
        __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_2, ccr_value);
    }
}
```

### 5.4 蓝牙驱动（BSP/bluetooth.c）

**发送（主控端）：**
```c
void BT_SendPacket(BT_ControlMode_t mode, uint8_t yaw, uint8_t pitch)
{
    uint8_t packet[6];
    packet[0] = 0xAA;
    packet[1] = mode;
    packet[2] = yaw;
    packet[3] = pitch;
    packet[4] = mode ^ yaw ^ pitch;  // 校验和
    packet[5] = 0x55;
    
    HAL_UART_Transmit(&huart1, packet, 6, 100);
}
```

**接收（从机端）：**
```c
void BT_ParseByte(uint8_t byte)
{
    switch(g_rx_state) {
        case STATE_WAIT_HEADER:
            if(byte == 0xAA) {
                g_rx_state = STATE_WAIT_MODE;
            }
            break;
        
        case STATE_WAIT_MODE:
            g_rx_packet.mode = byte;
            g_rx_state = STATE_WAIT_YAW;
            break;
        
        // ... 其他状态
        
        case STATE_WAIT_CHECKSUM:
            uint8_t checksum = g_rx_packet.mode ^ g_rx_packet.yaw ^ g_rx_packet.pitch;
            if(byte == checksum) {
                g_rx_state = STATE_WAIT_TAIL;
            } else {
                BT_ResetRxState();  // 校验失败，重新开始
            }
            break;
        
        case STATE_WAIT_TAIL:
            if(byte == 0x55) {
                g_packet_ready = true;  // 完整数据包接收成功
            }
            BT_ResetRxState();
            break;
    }
}
```

## 7. 调试过程记录

### 7.1 ADC读数固定问题

**现象：** ADC始终读取2048（对应90°），调整电位器无反应

**原因：**
1. Rank 2配置错误：使用了CHANNEL_0而非CHANNEL_1
2. 采样时间过短：1.5周期不足以对高阻抗电位器充分采样

**解决：**
```c
// adc.c 第62行和第72行
sConfig.SamplingTime = ADC_SAMPLETIME_55CYCLES_5;  // 从1.5改为55.5周期

// adc.c 第70行
sConfig.Channel = ADC_CHANNEL_1;  // Rank 2必须是CHANNEL_1
```

### 7.2 蓝牙供电电压不足

**现象：** HC-05 VCC仅1.3V，无法正常工作

**原因：** ST-LINK V2输出电流不足（<100mA），而HC-05需要30-50mA

**解决：** 改用STM32板载5V输出，并确保共地

### 7.3 高频数据丢失

**现象：** 手动串口发送正常，但20Hz连续发送时从机舵机不响应

**原因：** 从机接收任务 `osDelay(1)` 导致每次循环至少1ms，来不及处理DMA缓冲区（64字节@9600bps约67ms满）

**解决：**
```c
// freertos.c Task_DataReceive
osDelay(0);  // 让出CPU但不强制延时，改为立即重新调度
```

### 7.4 MPU6050初始化阻塞

**现象：** 添加MPU6050代码后，ADC模式也无法工作

**原因：** MPU6050初始化时I2C超时时间过长（100ms/次），多次失败累积导致启动阻塞

**解决：**
1. 缩短I2C超时：100ms → 10ms
2. 使用osDelay代替HAL_Delay：避免阻塞FreeRTOS调度器
3. 初始化失败时设置默认值并退出任务

```c
// mpu6050.c
HAL_I2C_Mem_Read(&hi2c1, MPU6050_I2C_ADDR, reg, I2C_MEMADD_SIZE_8BIT, data, 1, 10);

// freertos.c
if(MPU6050_Init() != 0) {
    g_mpu_yaw_angle = 90;
    g_mpu_pitch_angle = 90;
    vTaskDelete(NULL);  // 删除任务，不再占用CPU
}
```

### 7.5 I2C地址配置错误

**现象：** MPU6050初始化失败，无法通信

**原因：** 混淆了读写地址。HAL_I2C_Mem_Read/Write不需要区分读写位，库会自动处理

**修复：**
```c
// mpu6050.h
#define MPU6050_ADDR        0x68
#define MPU6050_I2C_ADDR    (MPU6050_ADDR << 1)  // 0xD0

// mpu6050.c - 统一使用MPU6050_I2C_ADDR
HAL_I2C_Mem_Write(&hi2c1, MPU6050_I2C_ADDR, reg, ...);
HAL_I2C_Mem_Read(&hi2c1, MPU6050_I2C_ADDR, reg, ...);
```

### 7.6 上电不工作但Reset正常

**现象：** 冷启动时舵机不动，按Reset后工作正常

**原因：** HC-05蓝牙模块上电初始化需要2秒，STM32启动过快导致蓝牙未完成配对就开始发送数据

**解决方案：**
上电后手动按Reset


### 7.7 MPU6050运输后失效

**现象：** 之前工作正常的陀螺仪模式，运输后角度固定不变（90°, 85°）

**可能原因：**
1. MPU6050硬件松动或损坏
2. I2C线路接触不良
3. 焊点虚焊

**排查步骤：**
1. 重新插拔MPU6050确认连接
2. 检查VCC、GND、SCL、SDA四根线
3. 按Reset测试是否恢复
4. 更换MPU6050模块

## 9. 常见问题

### 9.1 舵机抖动

**原因：** 
- 电源不足（舵机瞬时电流大）
- PWM信号不稳定

**解决：**
- 使用独立5V电源供电舵机
- 添加退耦电容（100uF）

### 9.2 蓝牙断连

**原因：**
- 主从机未共地
- 距离过远（>10米）
- 配对参数丢失

**解决：**
- 确认GND连接
- 缩短距离测试
- 重新AT配置并断电保存

### 9.3 陀螺仪漂移

**现象：** 静止时角度缓慢变化

**原因：** 互补滤波器长期积分误差

**改进：**
- 调整滤波系数（α从0.98降至0.95）
- 添加零偏校准

### 9.4 ADC读数不准

**检查：**
1. 电位器中间引脚是否连接到ADC引脚
2. 采样时间是否足够（55.5周期）
3. 电位器阻值是否合适（推荐10kΩ）

## 10. 注意事项

### 10.1 硬件连接
- **蓝牙供电**：HC-05必须使用5V供电，不可3.3V
- **舵机供电**：建议使用独立5V电源，两个SG90峰值电流可达2A
- **MPU6050上拉电阻**：模块必须自带4.7kΩ上拉，否则I2C通信失败
- **电位器接线**：中间引脚接ADC，两端接3.3V和GND

### 10.2 软件配置
- **ADC采样时间**：高阻抗电位器必须≥55.5周期，否则读数固定
- **ADC通道配置**：Rank 2必须配置为CHANNEL_1，不能重复使用CHANNEL_0
- **I2C超时时间**：建议10-20ms，过长会阻塞FreeRTOS启动
- **UART DMA接收**：高频数据使用`osDelay(0)`而非`osDelay(1)`
- **设备角色定义**：main.h中只能定义DEVICE_MASTER或DEVICE_SLAVE之一

### 10.3 蓝牙配置
- **主机HC-05**：AT+ROLE=1，AT+CMODE=0，AT+BIND绑定从机MAC
- **从机HC-05**：AT+ROLE=0
- **波特率**：9600（匹配USART1配置）
- **配对时序**：上电后需等待2秒让HC-05完成配对再启动数据传输

### 10.4 MPU6050使用
- **I2C地址**：AD0接GND时为0x68，HAL库使用0xD0（左移1位）
- **安装方向**：根据实际方向调整PITCH/ROLL到Yaw/Pitch的映射关系


### 10.5 调试技巧
- **串口监控**：连接从机USART1可实时查看接收到的蓝牙数据包
- **LED指示**：可添加LED闪烁指示MPU6050工作状态
- **Reset测试**：上电不工作时先按Reset，判断是否为蓝牙配对延迟

### 10.6 编译烧录
- **主控端**：在main.h中定义`DEVICE_MASTER`后编译烧录
- **从机端**：在main.h中定义`DEVICE_SLAVE`后编译烧录
- **不要混淆**：主控端固件烧录到从机会导致无响应
